# SAT SLAP — Asset Notes

## Visuals

- FIAT Sheep / white sheep / HODL White paw: game assets created for this project from user-supplied character references.
- The v1.2 sheep head sprites are technical crops of the game character assets for better hole alignment and faster recognition.
- Citadel Coffee background: stylized game illustration created from user-supplied location photographs.
- Hole graphic: created specifically for this prototype.

## Audio

- `background.mp3`: user-supplied background music. Rights remain with the respective rights holder. Confirm redistribution rights before making a public/forkable repository.
- Real sheep bleat: BigSoundBank, “Sheep #7”, sound no. 2349 by Joseph SARDIN. The source page states CC0/public-domain-equivalent, commercial use and redistribution allowed, attribution not required.
  - Source page: https://bigsoundbank.com/sheep-7-s2349.html
  - Runtime MP3: https://bigsoundbank.com/UPLOAD/mp3/2349.mp3
- Real-sheep fallback: Wikimedia Commons, “Sheep bleat.ogg” by Eviatar Bach, CC0 1.0.
  - Source page: https://commons.wikimedia.org/wiki/File:Sheep_bleat.ogg
- Strong slap and retro coin effects are synthesized locally with the browser Web Audio API. They are original SAT SLAP implementations inspired by general arcade sound-design techniques; no Nintendo/Mario audio file is included.
- `victory-fanfare.wav`: original SAT SLAP victory fanfare created for the game.
